# Locally hosted papers

Five entries link to PDFs that currently live on Prof. Mutlu's ETH page. Download
each one and save it here under the filename shown, and the site will serve its own copy.

| Save as | Download from |
|---|---|
| `genstore-asplos22.pdf`  | https://people.inf.ethz.ch/omutlu/pub/GenStore_asplos22-arxiv.pdf |
| `segram-isca22.pdf`      | https://people.inf.ethz.ch/omutlu/pub/SeGraM_genomic-sequence-mapping-universal-accelerator_isca22.pdf |
| `smash-micro19.pdf`      | https://people.inf.ethz.ch/omutlu/pub/SMASH-sparse-matrix-software-hardware-acceleration_micro19.pdf |
| `crow-isca19.pdf`        | https://people.inf.ethz.ch/omutlu/pub/CROW-DRAM-substrate-for-performance-energy-reliability_isca19.pdf |
| `cal-dram-micro18.pdf`   | https://people.inf.ethz.ch/omutlu/pub/CAL-DRAM_for-reduced-latency-memory_micro18.pdf |

`_data/publications.yml` already points at these paths. Until the files are here,
those five titles will link to a 404.

Anything else you want to self-host works the same way: drop the PDF in this folder
and set `url: /assets/papers/<filename>.pdf` on the entry.
